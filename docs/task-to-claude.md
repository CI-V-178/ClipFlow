# Claude向け実装指示書: PRIDEV-272 プロジェクト基盤の構築

## 1. タスク概要
* **タスクID**: PRIDEV-272
* **タスク名**: 【ClipFlow】プロジェクト基盤（Electron + Web UI）の構築
* **目的**: AI動画制作支援ローカルデスクトップアプリケーション「ClipFlow」の初期プロジェクトセットアップ、およびフロントエンド(Web UI)とバックエンド(Electron)の基盤構築を行う。

## 2. 前提知識・アーキテクチャ方針
* **ターゲット環境**: Windows (実行環境), macOS (開発環境)
* **利用技術**: Electron, Web技術 (React + TypeScript推奨), Vite (ビルドツール推奨)
* **設計方針**:
  * プレゼンテーション層（React）、アプリケーション層、インフラ層の層分離構造を意識すること。
  * OS依存処理、Electron依存処理（`ipcMain`, `ipcRenderer` など）は直接UI層で呼び出さず、`preload.js` (contextBridge) を経由したインターフェースで抽象化すること。

## 3. 具体的な実装指示（Step-by-Step）

### Step 1: 初期プロジェクトのセットアップ
1. Node.js環境下で、Electron + React + TypeScript + Vite の初期構成をセットアップしてください。
2. `tsconfig.json` などの各種静的解析ツールの初期設定を適切に行ってください。
3. `package.json` に開発環境起動用スクリプト（例: `npm run dev`）およびビルド用スクリプトを定義してください。

### Step 2: 依存分離構造（IPC通信基盤）の実装
1. Electronのメインプロセス（`main`ディレクトリ等）とレンダラープロセス（`renderer`ディレクトリ等）のディレクトリを明確に分離してください。
2. `preload.ts` (または `.js`) を作成し、`contextBridge.exposeInMainWorld` を用いて、UI側から安全に呼び出せるAPIインターフェースを定義してください。
3. 疎通確認用として、UI（React）からメインプロセスへメッセージを送り、返答を受け取る簡単なPing-Pong通信を実装してください。

### Step 3: 基本レイアウトの作成
1. Reactを用いて、アプリケーション全体のベースとなるレイアウト（アプリケーションシェル）を作成してください。
   * 画面構成案: サイドバー（ナビゲーション）、メインコンテンツ表示エリア、下部ステータスバーなど。
2. 複数画面の切り替えを想定し、React Router等を用いた簡易的なルーティング基盤を導入してください。
3. 全体のカラースキームやベースとなるCSS（可能であればモダンで洗練されたデザイン）の土台を構築してください。

## 4. 完了条件
* 開発コマンド（`npm run dev` 等）を実行し、Electronアプリとしてウィンドウがエラーなく立ち上がること。
* Web UI（React）が表示され、サイドバーなどの基本レイアウトが確認できること。
* IPC通信（UIからメインプロセスへのアクセス）が正常に動作していることが確認できること。
